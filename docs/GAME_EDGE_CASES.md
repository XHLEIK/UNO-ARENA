# UNO ARENA — Game Edge Cases

- Starter discard: WD4 illegal as starter (reshuffle); Wild color chosen; Draw Two/Reverse/Skip applied.
- Reverse in 2-player acts as Skip.
- Voluntary draw allowed; single draw per turn.
- Draw pile exhaustion reshuffles discard (top retained).
- WD4 challenge: success/failure penalties.
- UNO catch window closes on next action; idempotent catches.
- Stacking only when enabled; Draw Two on Draw Two only.
- Scoring: numbers face value, actions 20, wilds 50.
